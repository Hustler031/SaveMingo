# 🦩 SaveMingo

> **Save anything you find online.**  
> **Save it. Keep it.**

SaveMingo is being built as a clean, fast, mobile-first downloader platform. V1 focuses on public Instagram Reels, videos, photos, and carousels.

## Current phase
**SM-001 — Foundation**

The Instagram resolver is intentionally not connected yet. This branch establishes the app shell, diagnostics, health checks, AI handoff system, local Windows helpers, and CI foundation.

## Local start
On Windows, double-click:

`START_SAVEMINGO.cmd`

Health check:

`CHECK_SAVEMINGO.cmd`

Debug bundle:

`MAKE_DEBUG_REPORT.cmd`
